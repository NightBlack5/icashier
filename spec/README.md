# Spec do CashSave

Esta pasta descreve o estado real do CashSave após a auditoria e a organização
documental. O documento principal é [PROJETO.md](PROJETO.md).

## Status usado

- **Implementado:** existe no código e possui evidência local ou contrato
  versionado.
- **Parcial:** há implementação, mas a integração completa depende de serviço
  externo ou de uma verificação ainda não executada.
- **Planejado:** aparece como objetivo futuro, sem ser apresentado como
  funcionalidade concluída.
- **Não verificado:** o código/contrato existe, mas não foi possível comprovar o
  fluxo completo no ambiente disponível.

Este Spec não substitui os contratos `.xs` do diretório `xano/` nem os changes
OpenSpec. Ele consolida a visão técnica para manutenção e onboarding.
