# Proposta: versionar-projeto-git

## Why

O projeto precisa de histórico de alterações e de um repositório compartilhado pelo grupo. Também é preciso impedir que ambientes virtuais, arquivos gerados e credenciais sejam enviados.

## What Changes

- Inicializar o repositório Git.
- Criar e revisar o `.gitignore`.
- Fazer o primeiro commit.
- Ligar o repositório ao GitHub e enviar.

Fora do escopo desta mudança: fluxos de colaboração em equipe, como pull requests e revisão.

## Capabilities

### New Capabilities
- `version-control`: Versionar o projeto com Git e mantê-lo em um repositório remoto, sem arquivos pesados nem segredos.

### Modified Capabilities
- Nenhuma.

## Impact

- Projeto: CashSave (Python + Reflex, backend em Xano).
- Referência visual: capturas da versão antiga (Base44). Nenhum código copiado.
