# Ocultar e-mail da interface

## Objetivo

Impedir que o e-mail da conta autenticada seja exibido na navegação e nas
áreas internas do CashSave.

## Escopo

- Remover o e-mail dos blocos de usuário exibidos nas páginas principais.
- Manter o nome e avatar para identificação visual.
- Verificar que a assistente não recebe o e-mail no contexto financeiro.

## Fora de escopo

- Remover o e-mail dos dados necessários para login ou autenticação.
- Alterar o cadastro ou a API do usuário.
