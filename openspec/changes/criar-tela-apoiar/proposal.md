# Proposta: criar-tela-apoiar

## Why

O CashSave é gratuito e aceita apoio opcional dos usuários. A tela explica o projeto e oferece o Pix.

## What Changes

- Criar o texto de apoio ao projeto.
- Exibir o QR Code e a chave Pix.
- Criar o botão que copia a chave.

Fora do escopo desta mudança: processamento de pagamentos e registro de doações.

## Capabilities

### New Capabilities
- `donation-screen`: Apresentar a tela de apoio ao projeto com Pix, QR Code e botão para copiar a chave.

### Modified Capabilities
- Nenhuma.

## Impact

- Projeto: CashSave (Python + Reflex, backend em Xano).
- Referência visual: capturas da versão antiga (Base44). Nenhum código copiado.
